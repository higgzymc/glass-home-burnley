# Glass Home 1.5 — Scenic

Native Fire TV launcher with a scenic wallpaper, mountain-depth clock, saved editable favourites, and local weather. Hold Select on an app to add or remove it from Home. Settings links open native Fire TV categories directly.

Weather uses the internet; app launching works offline. Choose a UK postcode/town for accurate local placement, or approximate IP location for travel. Weather checks every five minutes while Home is active. Personal device settings are not included in the APK or repository.

See README.md for installation, privacy, controls and build instructions. The Windows installer preserves existing accessibility services and does not uninstall other apps.
